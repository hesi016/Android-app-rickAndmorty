# Rick and Morty

En Android-app med innhold fra Rick and Morty, utviklet som
eksamensprosjekt i Android-programmering på Kristiania.


## Teknologier
- Kotlin

## Kjøre prosjektet
1. Klon dette repositoryet.
2. Åpne prosjektet i Android Studio.
3. La Gradle laste inn avhengighetene.
4. Kjør appen på en emulator eller Android-enhet.
